# SPK Promosi Jabatan - ESPEOKA

Frontend application untuk Sistem Pendukung Keputusan (SPK) Promosi Jabatan ESPEOKA.

## Description

ESPEOKA merupakan sistem pendukung keputusan yang membantu proses evaluasi dan rekomendasi promosi jabatan karyawan.

Frontend ini menjadi draft awal antarmuka sistem sebelum dilakukan integrasi dengan backend dan database.

## Current Draft

- Landing page
- Login
- HRD Dashboard
- Assessment / Penilaian Kandidat
- Hasil Ranking SAW
- Approval Promosi
